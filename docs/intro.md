# 로블록스 루아 교육에 오신 것을 환영합니다!

초등학생을 위한 로블록스 루아 스크립트 학습 사이트입니다.

## 이 사이트는 누구를 위한 것인가요?

- 엔트리나 스크래치로 블록 코딩을 해본 적 있는 친구들
- 로블록스에서 자신만의 게임을 만들고 싶은 친구들
- 텍스트 코딩에 도전해보고 싶은 친구들

## 18주 커리큘럼 개요

우리의 교육 과정은 6단계로 나뉘어져 있어요:

| 단계 | 기간 | 학습 내용 |
|------|------|----------|
| **1단계** | 1-3주차 | 로블록스 스튜디오 인터페이스와 3D 모델링 |
| **2단계** | 4-6주차 | 루아 스크립트 기초와 속성 제어 |
| **3단계** | 7-9주차 | 이벤트와 조건문을 활용한 게임 메커니즘 |
| **4단계** | 10-12주차 | 시스템 구축과 게임 게시 |
| **5단계** | 13-15주차 | Rojo 플러그인을 통한 외부 에디터 연동 |
| **6단계** | 16-18주차 | 고급 GUI 만들기 |

## 블록 코딩에서 텍스트 코딩으로

엔트리에서 배웠던 블록들은 루아 코드와 1:1로 대응돼요!

| 엔트리 블록 | 루아 코드 |
|------------|----------|
| 계속 반복하기 | `while true do` |
| 만약 ~라면 | `if 조건 then` |
| 변수 값 정하기 | `local 변수 = 값` |
| ~에 닿았는가? | `Part.Touched:Connect()` |

:::tip 걱정하지 마세요!
텍스트 코딩이 처음이라 어렵게 느껴질 수 있지만, 이미 블록 코딩으로 배운 논리를 새로운 '언어'로 쓰는 것뿐이에요!
:::

## 만들게 될 프로젝트들

이 과정을 통해 다음과 같은 프로젝트를 완성하게 됩니다:

- **킬 파트**: 닿으면 캐릭터가 사망하는 장애물
- **리더보드**: 점수를 표시하는 시스템
- **상점 시스템**: 아이템을 구매할 수 있는 상점
