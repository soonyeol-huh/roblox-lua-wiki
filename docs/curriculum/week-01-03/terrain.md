# 지형(Terrain) 만들기

파트로 작은 물체들을 만들었다면, 이제 터레인(Terrain)으로 넓은 땅과 자연환경을 만들어볼 거예요!

## 학습 목표

- 터레인 에디터를 사용할 수 있다
- 다양한 지형 재질을 적용할 수 있다
- 물(Water)을 추가할 수 있다

## 터레인 에디터 열기

1. 상단 메뉴에서 `Home` 탭을 클릭합니다
2. `Editor` 버튼 아래의 화살표를 클릭합니다
3. `Terrain Editor`를 선택합니다

## 터레인 도구 소개

### 생성 도구 (Create)

```
Region: 사각형 영역을 한 번에 채웁니다
Draw: 브러시로 그리듯이 지형을 만듭니다
```

### 변형 도구 (Edit)

| 도구 | 기능 | 사용 예 |
|------|------|--------|
| Add | 지형을 추가 | 산 만들기 |
| Subtract | 지형을 깎기 | 동굴 파기 |
| Grow | 부드럽게 키우기 | 언덕 만들기 |
| Erode | 부드럽게 깎기 | 계곡 만들기 |
| Smooth | 표면 매끄럽게 | 울퉁불퉁한 곳 정리 |
| Flatten | 평평하게 | 건물 지을 땅 만들기 |
| Paint | 재질 칠하기 | 잔디 → 모래로 바꾸기 |

## 지형 재질 종류

터레인에는 다양한 재질이 있어요:

### 자연 재질
- **Grass**: 초록색 잔디
- **Sand**: 노란색 모래
- **Rock**: 회색 바위
- **Snow**: 하얀 눈
- **Mud**: 갈색 진흙
- **Ice**: 미끄러운 얼음

### 물 재질
- **Water**: 수영할 수 있는 물!

### 기타 재질
- **Concrete**: 콘크리트
- **Asphalt**: 아스팔트 도로
- **Brick**: 벽돌

## 산 만들기 실습

### 1단계: 기본 땅 만들기

1. Region 도구 선택
2. Material을 `Grass`로 설정
3. Position과 Size를 조절하여 넓은 평지 생성
4. `Fill` 버튼 클릭

### 2단계: 산 추가하기

1. Add 도구 선택
2. Brush Size를 크게 설정 (20~30)
3. Material을 `Rock`으로 설정
4. 마우스를 클릭하면서 산의 형태를 만듭니다

### 3단계: 매끄럽게 다듬기

1. Smooth 도구 선택
2. 울퉁불퉁한 부분을 문질러서 매끄럽게 만듭니다

### 4단계: 꼭대기에 눈 추가

1. Paint 도구 선택
2. Material을 `Snow`로 설정
3. 산 꼭대기를 칠합니다

## 물 추가하기

:::tip 물의 특별한 기능
Water 재질은 플레이어가 수영할 수 있어요!
:::

### 호수 만들기

1. Subtract 도구로 땅에 웅덩이를 팝니다
2. Region 도구 선택
3. Material을 `Water`로 설정
4. 웅덩이 영역에 물을 채웁니다

### 물 속성 조절하기

탐색기에서 `Workspace > Terrain`을 선택하면 물 관련 속성을 바꿀 수 있어요:

| 속성 | 설명 |
|------|------|
| WaterColor | 물 색깔 |
| WaterReflectance | 반사 정도 |
| WaterTransparency | 투명도 |
| WaterWaveSize | 파도 크기 |
| WaterWaveSpeed | 파도 속도 |

## 생성 템플릿 활용하기

터레인 에디터의 `Generate` 탭을 사용하면 자동으로 지형을 만들 수 있어요.

### 사용 방법

1. Terrain Editor에서 `Generate` 탭 클릭
2. Map Settings에서 크기 설정
3. Biome 선택 (사막, 숲, 북극 등)
4. `Generate` 버튼 클릭

:::caution 주의!
Generate를 누르면 기존 터레인이 전부 지워져요.
먼저 게임을 저장해두세요!
:::

## 연습 문제

:::note 실습해보기
섬 맵을 만들어보세요:

1. **바다 만들기**
   - 큰 영역을 Water로 채웁니다

2. **섬 만들기**
   - 바다 중앙에 Add 도구로 땅을 올립니다
   - Grass 재질을 사용하세요

3. **해변 만들기**
   - Paint 도구로 물가 주변을 Sand로 칠합니다

4. **산 추가**
   - 섬 중앙에 작은 산을 만들어보세요
   - Rock 재질을 사용하세요

5. **꾸미기**
   - Toolbox에서 나무 모델을 검색해서 추가해보세요!
:::
