# 파트와 도구 사용하기

로블록스에서 모든 물체의 기본 단위는 **파트(Part)**예요. 레고 블록처럼 파트를 조립해서 멋진 건물이나 장애물을 만들 수 있어요!

## 학습 목표

- 파트를 생성하고 삭제할 수 있다
- 이동, 크기, 회전 도구를 사용할 수 있다
- 앵커(Anchor)의 개념을 이해한다

## 파트 만들기

### 파트 추가하기

1. 상단 메뉴에서 `Model` 탭을 클릭합니다
2. `Part` 버튼을 클릭합니다
3. Block, Sphere, Cylinder 등 원하는 모양을 선택합니다

```
파트 종류:
- Block: 네모난 블록 (가장 기본)
- Sphere: 둥근 공
- Cylinder: 원기둥
- Wedge: 삼각형 모양의 경사면
```

### 파트 삭제하기

- 파트를 선택한 후 `Delete` 키를 누릅니다
- 또는 탐색기에서 파트를 오른쪽 클릭 → Delete

## 변형 도구 사용하기

### 이동 도구 (Move)

단축키: `Ctrl + 2`

```
파트를 원하는 위치로 옮길 수 있어요.
빨간색 화살표: X축 (좌우)
초록색 화살표: Y축 (위아래)
파란색 화살표: Z축 (앞뒤)
```

:::tip 정밀 이동
Ctrl 키를 누른 채로 이동하면 1 스터드(stud) 단위로 정확하게 움직여요!
:::

### 크기 도구 (Scale)

단축키: `Ctrl + 3`

```
파트의 크기를 조절할 수 있어요.
각 면의 점을 드래그하면 크기가 바뀝니다.
```

### 회전 도구 (Rotate)

단축키: `Ctrl + 4`

```
파트를 회전시킬 수 있어요.
각 축을 기준으로 돌릴 수 있습니다.
```

## 앵커(Anchor) 이해하기

:::caution 중요한 개념!
앵커는 물체를 공중에 고정시키는 기능이에요!
:::

### 앵커가 꺼져있을 때

```
게임을 실행하면 파트가 중력에 의해 아래로 떨어져요.
현실 세계처럼 물리 법칙이 적용됩니다!
```

### 앵커가 켜져있을 때

```
파트가 그 자리에 고정되어 움직이지 않아요.
건물이나 고정된 장애물을 만들 때 필수!
```

### 앵커 설정 방법

1. 파트를 선택합니다
2. 속성(Properties) 창에서 `Anchored`를 찾습니다
3. 체크박스를 켜면(✓) 고정, 끄면 떨어집니다

또는 상단 Model 탭에서 `Anchor` 버튼을 클릭해도 됩니다.

## 파트 속성 바꾸기

속성 창에서 파트의 다양한 특성을 바꿀 수 있어요.

| 속성 | 설명 | 예시 |
|------|------|------|
| Name | 파트의 이름 | "KillPart", "Floor" |
| BrickColor | 파트의 색깔 | Really red, Bright blue |
| Material | 재질 | Plastic, Wood, Neon |
| Transparency | 투명도 (0~1) | 0.5 = 반투명 |
| CanCollide | 충돌 여부 | 꺼면 통과 가능 |

### 색깔 바꾸기

1. 파트 선택
2. 속성에서 `BrickColor` 또는 `Color` 찾기
3. 원하는 색 선택

### 재질 바꾸기

```
Material 속성을 바꾸면 나무, 금속, 네온 등
다양한 재질로 표현할 수 있어요!
```

**재질 종류:**
- Plastic: 기본 플라스틱
- Wood: 나무
- Metal: 금속
- Neon: 발광 (빛남!)
- Glass: 유리 (반투명)

## 연습 문제

:::note 실습해보기
다음 순서대로 간단한 집을 만들어보세요:

1. 바닥 만들기
   - 큰 Block 파트를 만들고 납작하게 만듭니다
   - Anchored를 켜세요
   - Material을 Wood로 바꿔보세요

2. 벽 만들기
   - 4개의 Block 파트로 벽을 세웁니다
   - 모든 벽을 Anchored 시키세요
   - 색깔을 통일해보세요

3. 지붕 만들기
   - Wedge 파트 2개로 삼각형 지붕을 만들어보세요
   - Anchored 잊지 마세요!
:::
