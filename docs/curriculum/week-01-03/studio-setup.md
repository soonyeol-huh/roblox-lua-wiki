# 로블록스 스튜디오 설치 및 환경 설정

로블록스 스튜디오는 로블록스 게임을 만들 수 있는 무료 프로그램이에요. 엔트리에서 '무대'를 꾸미듯이, 여기서는 3D 공간을 만들 거예요!

## 학습 목표

- 로블록스 스튜디오를 설치할 수 있다
- 스튜디오의 기본 화면 구성을 이해한다
- 탐색기, 속성, 도구 상자의 역할을 알 수 있다

## 로블록스 스튜디오 설치하기

### 1단계: 로블록스 계정 만들기

1. 로블록스 웹사이트에 접속합니다
2. 회원가입을 진행합니다 (부모님의 도움을 받으세요!)
3. 이메일 인증을 완료합니다

### 2단계: 스튜디오 다운로드

1. 로블록스에 로그인합니다
2. 상단 메뉴에서 "만들기(Create)"를 클릭합니다
3. "Studio 다운로드"를 클릭합니다
4. 설치 파일을 실행하여 설치합니다

## 스튜디오 화면 구성

스튜디오를 처음 열면 여러 창이 보여요. 각각의 역할을 알아볼까요?

![스튜디오 화면 구성](/img/screenshots/part-types.png)

위 화면에서 왼쪽에는 **속성(Properties)** 창, 오른쪽에는 **탐색기(Explorer)** 창, 가운데에는 **3D 뷰포트**, 위에는 **도구 모음**이 있어요.

### 탐색기 (Explorer)

```
게임의 모든 물체들이 목록으로 정리된 곳이에요.
마치 컴퓨터의 폴더처럼 계층 구조로 되어 있어요.
```

**주요 폴더들:**
- `Workspace`: 게임 안에 보이는 모든 물체
- `Players`: 게임에 접속한 플레이어 정보
- `ServerScriptService`: 서버에서 실행되는 스크립트

### 속성 (Properties)

```
선택한 물체의 모든 정보를 보여줘요.
색깔, 크기, 위치 등을 여기서 바꿀 수 있어요!
```

**자주 사용하는 속성:**
- `Name`: 물체의 이름
- `Color`: 색깔
- `Size`: 크기 (X, Y, Z)
- `Position`: 위치

### 도구 상자 (Toolbox)

```
다른 사람들이 만든 모델이나 에셋을 가져올 수 있어요.
무료 모델을 검색해서 내 게임에 넣을 수 있답니다!
```

## 기본 조작법

### 카메라 이동

| 조작 | 방법 |
|------|------|
| 화면 회전 | 마우스 오른쪽 버튼 + 드래그 |
| 화면 이동 | 마우스 휠 버튼 + 드래그 |
| 확대/축소 | 마우스 휠 스크롤 |
| 빠른 이동 | W, A, S, D 키 (오른쪽 버튼 누른 상태) |

### 물체 선택

- 클릭: 물체 선택
- Ctrl + 클릭: 여러 물체 선택
- Ctrl + A: 모든 물체 선택

## 연습 문제

:::note 실습해보기
1. 로블록스 스튜디오를 열어보세요
2. 새 프로젝트를 만들어보세요 (Baseplate 템플릿)
3. 탐색기에서 "Baseplate"를 찾아 클릭해보세요
4. 속성 창에서 색깔(BrickColor)을 바꿔보세요
:::
