# 로블록스용 3D 모델링

로블록스 게임에 사용할 에셋을 블렌더에서 효율적으로 만드는 방법을 배워봐요! 폴리곤 수 관리부터 실전 게임 에셋 제작까지 다룹니다.

## 학습 목표

- 로블록스에 적합한 로우 폴리 모델링을 할 수 있다
- 게임 에셋(무기, 가구, 소품)을 모델링할 수 있다
- 모델의 원점과 크기를 로블록스에 맞게 설정할 수 있다

## 로우 폴리(Low Poly)란?

```
로우 폴리 = 적은 수의 폴리곤으로 만든 3D 모델

하이 폴리 (영화용):     로우 폴리 (게임용):
  50,000+ 폴리곤         100~5,000 폴리곤
  매우 부드럽고 정교      약간 각져도 괜찮음
  렌더링 느림             실시간 게임에 적합!

로블록스 권장 폴리곤 수:
  소품 (보석, 열쇠):      50~500
  무기 (칼, 총):          200~2,000
  캐릭터 악세서리:        500~4,000
  건물/가구:              500~5,000
```

:::tip 폴리곤 수 확인하기
뷰포트 왼쪽 상단에서 **Viewport Overlays** → **Statistics** 체크하면 Tris(삼각형) 수가 표시돼요. 로블록스 메시는 **10,000 Tris 이하**를 권장해요!
:::

## 로블록스 크기 기준

```
로블록스 1 stud = 블렌더 약 0.28m

캐릭터 키:     약 5 studs = 블렌더 1.4m
문 높이:       약 7 studs = 블렌더 2.0m
의자 높이:     약 3 studs = 블렌더 0.84m

💡 정확한 크기보다는 비율이 중요해요!
   로블록스에서 임포트 후 Scale 조절이 가능합니다.
```

## 실습 1: 게임용 칼 만들기

### 1단계: 칼날

```
1. 기본 큐브 선택
2. Tab → 편집 모드
3. 면 모드 (3 키)
4. 윗면 선택 → E(돌출) → Z → 2 → Enter
5. S → X → 0.5 → Enter (윗부분 좁히기)
6. 다시 윗면 → E → Z → 0.3 → Enter
7. S → X → 0 → Enter (끝 뾰족하게)
```

### 2단계: 칼날 단면

```
1. 옆면 선택 (양쪽 다)
2. Ctrl + R → 칼날 가운데로 루프 컷 추가
3. 가운데 선(Edge) 선택 → G → Y → 0.1 → Enter
   (칼날에 등 만들기)
```

### 3단계: 가드(코등이)

```
1. Tab → 오브젝트 모드
2. Shift + A → Mesh → Cube
3. S → X → 1.5 → Enter
4. S → Y → 1.5 → Enter
5. S → Z → 0.2 → Enter
6. G → Z → (칼날 아래 위치로 이동)
```

### 4단계: 손잡이

```
1. Shift + A → Mesh → Cylinder
2. Vertices: 8 (로우 폴리!)
3. S → 0.3 → Enter
4. S → Z → 1.5 → Enter
5. R → X → 90 → Enter (눕히기... 필요시)
6. G → Z → (가드 아래로 이동)
```

### 5단계: 합치기 & 정리

```
1. 모든 파트 선택 (A 키)
2. Ctrl + J (합치기)
3. Tab → 편집 모드
4. A (전체 선택) → M → By Distance (겹친 점 합치기)
```

## 실습 2: 보물 상자 만들기

### 1단계: 상자 본체

```
1. 기본 큐브 시작
2. S → Z → 0.6 → Enter (납작하게)
3. Tab → 편집 모드
4. Ctrl + R → Z축 루프 컷 1개 (가운데 나누기)
```

### 2단계: 뚜껑 부분

```
1. 면 모드 → 윗면 선택
2. E → Z → 0.3 → Enter (뚜껑 돌출)
3. 뚜껑 옆면 선택
4. S → Z → 약간 줄이기 (살짝 둥근 느낌)
```

### 3단계: 장식 추가

```
1. 앞면 선택
2. I (Inset) → 적당히 줄이기
3. E → Y → -0.05 → Enter (살짝 들어가게)
   → 자물쇠가 들어갈 홈 표현!
```

## 원점(Origin) 설정

```
원점 = 오브젝트의 기준점 (주황색 점)

로블록스에서 메시를 임포트하면
원점이 파트의 중심이 돼요!

칼:    손잡이 아래쪽에 원점 → 캐릭터가 자연스럽게 잡음
모자:  아랫면 중앙에 원점 → 머리 위에 딱 맞음
나무:  밑동에 원점 → 바닥에 배치하기 쉬움
```

### 원점 이동 방법

```
1. 오브젝트 모드에서 오브젝트 선택
2. 마우스 오른쪽 클릭 → Set Origin
3. 선택지:
   - Origin to Geometry: 오브젝트 중심으로
   - Origin to 3D Cursor: 3D 커서 위치로
   - Geometry to Origin: 오브젝트를 원점으로 이동

💡 3D 커서를 원하는 위치에 놓고
   "Origin to 3D Cursor"가 가장 정확해요!

3D 커서 이동: Shift + 오른쪽 클릭
3D 커서 초기화: Shift + C
```

## 스무딩(Smoothing)

### 플랫 셰이딩 vs 스무스 셰이딩

```
플랫 셰이딩:          스무스 셰이딩:
  각진 느낌              부드러운 느낌
  ┌─╲                    ╭─╲
  │  ╲                   │  ╲
  면이 보임               면이 안 보임

오른쪽 클릭 → Shade Smooth (부드럽게)
오른쪽 클릭 → Shade Flat (각지게)
```

### Auto Smooth

```
스무스 셰이딩 + 날카로운 모서리를 동시에!

1. Shade Smooth 적용
2. 속성 패널 → 오브젝트 데이터 (초록 삼각형 아이콘)
3. Normals → Auto Smooth 체크
4. Angle: 30° (30도보다 날카로운 모서리는 각지게)

💡 게임 에셋에 가장 많이 쓰이는 설정이에요!
```

## 모델링 팁

### 이름 붙이기

```
아웃라이너에서 오브젝트를 더블클릭하면 이름 변경 가능!

나쁜 예: Cube, Cube.001, Cube.002
좋은 예: Sword_Blade, Sword_Guard, Sword_Handle

💡 로블록스에 임포트할 때 이름이 보이니까
   알아보기 쉽게 지어주세요!
```

### Apply 잊지 않기!

```
크기/회전을 변경한 뒤 반드시:
Ctrl + A → All Transforms

이유: 블렌더 내부 값을 초기화해서
      로블록스에 가져갈 때 문제가 안 생겨요!

Scale이 (1, 1, 1)이 아니면 ⚠️ 위험!
Ctrl + A로 항상 초기화하세요.
```

## 연습 문제

:::note 실습해보기
1. **로우 폴리 나무**
   - 원기둥(Cylinder, 6~8 Vertices)으로 나무 기둥
   - Ico Sphere(Subdivisions: 1)로 나뭇잎
   - 합쳐서 하나의 나무 완성

2. **게임용 칼**
   - 위 실습을 따라 칼 만들기
   - 원점을 손잡이 아래쪽으로 설정
   - Auto Smooth 적용

3. **보물 상자**
   - 위 실습을 따라 상자 만들기
   - 장식 디테일 추가해보기

4. **나만의 게임 소품**
   - 물약 병, 방패, 보석 등 자유롭게
   - 폴리곤 수 5,000 이하로 유지
:::
