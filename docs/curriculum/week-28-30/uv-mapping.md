# UV 매핑

3D 모델에 그림(텍스처)을 입히려면 **UV 매핑**이 필요해요. 3D 모양을 2D로 펼치는 작업인데, 선물 포장지를 펼치는 것과 비슷해요!

## 학습 목표

- UV 매핑의 개념을 이해한다
- 기본적인 UV 언랩(Unwrap)을 할 수 있다
- 로블록스 메시에 적합한 UV를 만들 수 있다

## UV 매핑이란?

```
3D 모델에 2D 이미지를 입히려면?
→ 3D를 2D로 "펼쳐야" 해요!

   3D 큐브          UV 전개도
   ┌──┐
  ╱  ╱│         ┌──┬──┬──┬──┐
 ┌──┐ │    →    │  │  │  │  │
 │  │ ╱         ├──┼──┼──┼──┤
 └──┘           │  │  │  │  │
                └──┴──┴──┴──┘
 상자 접기 전의 전개도를 생각하면 돼요!
```

### U와 V가 뭐예요?

```
3D 공간: X, Y, Z 축
2D 이미지: U, V 축

U = 가로 방향 (X와 비슷)
V = 세로 방향 (Y와 비슷)

X,Y,Z와 겹치지 않게 U,V라는 이름을 써요!
```

## UV 에디터 열기

### 화면 분할

```
1. 뷰포트 상단 모서리에 마우스를 올리면 + 커서가 나타남
2. 왼쪽으로 드래그 → 화면이 2개로 분할!
3. 왼쪽 화면: Editor Type을 "UV Editor"로 변경
4. 오른쪽 화면: 3D 뷰포트 유지

┌─────────────┬──────────────┐
│             │              │
│  UV Editor  │  3D Viewport │
│             │              │
└─────────────┴──────────────┘
```

## 기본 UV 언랩

### Smart UV Project (자동)

가장 쉬운 방법이에요!

```
1. 오브젝트 선택
2. Tab → 편집 모드
3. A (전체 선택)
4. U 키 → Smart UV Project
5. OK 클릭

→ 블렌더가 자동으로 UV를 펼쳐줘요!
```

### Unwrap (수동)

더 깔끔한 결과를 원할 때:

```
1. Tab → 편집 모드
2. 선 모드 (2 키)
3. 잘라낼 선(Seam)을 선택
4. Ctrl + E → Mark Seam (빨간 선이 됨)
5. A (전체 선택)
6. U → Unwrap

Seam = 가위로 자르는 선
  종이 상자를 펼칠 때 칼로 잘라야 하는 부분!
```

### 큐브 UV 언랩 예시

```
Seam을 어디에 넣을까?

    ┌──┐
   ╱  ╱│
  ┌──┐ │   ← 빨간 선 = Seam
  │  │╱
  └──┘

뒷면과 아랫면의 모서리를 Seam으로 표시하면:

  ┌──┬──┬──┬──┐
  │위│앞│아래│뒤│
  ├──┼──┼──┼──┤
  │왼│  │오른│  │
  └──┴──┴──┴──┘

깔끔하게 펼쳐져요!
```

## UV 에디터에서 편집

### UV 정리하기

```
UV 에디터에서도 같은 도구를 쓸 수 있어요:

G: UV 이동
R: UV 회전
S: UV 크기 조절

💡 UV가 정사각형(0~1) 안에 들어가야 해요!
   벗어나면 텍스처가 잘려요.
```

### UV 겹치지 않게

```
⚠️ UV 섬(Island)들이 겹치면 안 돼요!

나쁜 예:            좋은 예:
┌──────┐           ┌──────┐
│ ┌─┐  │           │ ┌─┐  │
│ │█│  │           │ │ │  │
│ └─┘  │           │ └─┘  │
│  ┌─┐ │           │      │
│  │█│ │           │  ┌─┐ │
│  └─┘ │           │  │ │ │
└──────┘           └──────┘
 겹침!              깔끔!
```

### 빈 공간 최소화

```
UV 정사각형 안에 빈 공간을 줄이세요!

비효율적:           효율적:
┌──────┐           ┌──────┐
│ ┌┐   │           │┌──┐  │
│ └┘   │           │└──┘  │
│      │           │┌─┐┌─┐│
│   ┌┐ │           │└─┘└─┘│
│   └┘ │           │ ┌──┐ │
└──────┘           └──────┘
 공간 낭비!          꽉 채움!

UV → Pack Islands (P 키)로 자동 정리!
```

## 로블록스용 UV 팁

### 텍스처 해상도

```
로블록스 텍스처 권장 크기:

소품:        256 × 256 px
무기/장비:   512 × 512 px
큰 오브젝트: 1024 × 1024 px

⚠️ 로블록스 최대 텍스처: 1024 × 1024 px
   그 이상은 자동 축소돼요!
```

### Color ID Map

```
복잡한 텍스처 대신 영역별 색 구분만 해도 충분해요!

칼 UV에 색칠:
┌──────────────┐
│ ██ 칼날(은색) │
│ ██ 가드(금색) │
│ ██ 손잡이(갈색)│
└──────────────┘

로블록스에서 머티리얼/색상으로 대체 가능!
```

## 실습: 칼에 UV 입히기

### 1단계: Seam 표시

```
1. 칼 모델을 편집 모드로
2. 선 모드 (2 키)
3. 칼날/가드/손잡이 경계 선을 선택
4. Ctrl + E → Mark Seam
5. 칼날 뒷면 세로 선도 Seam 표시
```

### 2단계: 언랩

```
1. A (전체 선택)
2. U → Unwrap
3. UV 에디터에서 결과 확인
4. 필요하면 UV 섬 위치 정리
```

### 3단계: 텍스처 확인

```
1. UV 에디터 → Image → New (512x512)
2. UV 에디터 → UV → Export UV Layout
3. PNG로 저장
4. 그림판이나 포토샵에서 색칠 가능!
```

## 연습 문제

:::note 실습해보기
1. **큐브 UV 언랩**
   - 기본 큐브에 Seam 표시하기
   - Unwrap으로 깔끔하게 펼치기
   - UV 에디터에서 결과 확인

2. **Smart UV Project 체험**
   - 이전에 만든 모델에 Smart UV Project 적용
   - 자동 결과와 수동 결과 비교해보기

3. **칼 UV 매핑**
   - 위 실습을 따라 칼에 UV 적용
   - UV Layout 내보내기

4. **UV 그림 그리기 (도전)**
   - 내보낸 UV Layout PNG를 그림판으로 열기
   - 각 영역에 색칠하기
   - 블렌더에서 텍스처로 적용해보기
:::
