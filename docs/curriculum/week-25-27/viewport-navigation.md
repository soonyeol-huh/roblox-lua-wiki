# 뷰포트 조작과 기본 도구

블렌더에서 3D 공간을 자유롭게 돌아다니고, 오브젝트를 이동/회전/크기 조절하는 방법을 배워봐요!

## 학습 목표

- 뷰포트를 자유롭게 조작할 수 있다
- 오브젝트를 선택, 이동, 회전, 크기 조절할 수 있다
- 블렌더의 단축키를 활용할 수 있다

## 뷰포트 조작

### 마우스로 카메라 조작

| 조작 | 방법 | 로블록스 스튜디오 비교 |
|------|------|----------------------|
| 화면 회전 | 마우스 가운데 버튼 드래그 | 오른쪽 버튼 드래그 |
| 화면 이동 | Shift + 가운데 버튼 드래그 | 가운데 버튼 드래그 |
| 확대/축소 | 마우스 휠 스크롤 | 마우스 휠 스크롤 |

:::tip 가운데 버튼이 없다면?
Edit → Preferences → Input에서 **Emulate 3 Button Mouse**를 체크하세요. Alt + 왼쪽 버튼으로 가운데 버튼을 대신할 수 있어요!
:::

### 숫자 키패드로 시점 변경

```
┌─────────────────────────────┐
│  시점 전환 (숫자 키패드)      │
│                              │
│  Numpad 1: 앞에서 보기 (Front) │
│  Numpad 3: 옆에서 보기 (Right) │
│  Numpad 7: 위에서 보기 (Top)   │
│  Numpad 5: 원근/정면 전환      │
│  Numpad 0: 카메라 시점         │
│                              │
│  Ctrl + Numpad 1: 뒤에서 보기  │
│  Ctrl + Numpad 3: 왼쪽에서 보기 │
└─────────────────────────────┘
```

:::tip 숫자 키패드가 없다면?
Edit → Preferences → Input에서 **Emulate Numpad**를 체크하세요. 키보드 상단 숫자 키로 대신할 수 있어요!
:::

### 빠른 시점 이동

- **`~` (물결) 키**: 시점 파이 메뉴 (Front, Back, Top 등 선택)
- **`.` (마침표) 키 (넘패드)**: 선택한 오브젝트에 포커스
- **Home 키**: 전체 장면 보기

## 오브젝트 선택

### 기본 선택

| 조작 | 방법 |
|------|------|
| 선택 | 왼쪽 클릭 |
| 추가 선택 | Shift + 왼쪽 클릭 |
| 전체 선택 | A 키 |
| 선택 해제 | Alt + A 키 |
| 영역 선택 | B 키 → 드래그 |

### 선택 확인하기

```
선택되면 → 주황색 테두리가 나타남!
선택 안됨 → 테두리 없음

🟧 선택됨        ⬜ 선택 안됨
```

## 이동, 회전, 크기 조절

블렌더에서 가장 많이 쓰는 3가지 도구예요!

### 이동 (Grab) - G 키

```
G 키 누르기 → 마우스 이동 → 클릭으로 확정

축 제한:
  G → X: X축으로만 이동 (빨간색)
  G → Y: Y축으로만 이동 (초록색)
  G → Z: Z축으로만 이동 (파란색)

취소: 오른쪽 클릭 또는 Esc
```

### 회전 (Rotate) - R 키

```
R 키 누르기 → 마우스 이동 → 클릭으로 확정

축 제한:
  R → X: X축 기준 회전
  R → Y: Y축 기준 회전
  R → Z: Z축 기준 회전

정확한 값:
  R → Z → 90 → Enter: Z축으로 정확히 90도 회전
```

### 크기 조절 (Scale) - S 키

```
S 키 누르기 → 마우스 이동 → 클릭으로 확정

축 제한:
  S → X: X축으로만 크기 조절
  S → Y: Y축으로만 크기 조절
  S → Z: Z축으로만 크기 조절

정확한 값:
  S → 2 → Enter: 2배로 키우기
  S → 0.5 → Enter: 절반으로 줄이기
```

### 축 색깔 기억하기

```
X축 = 빨간색 🔴  (좌우)
Y축 = 초록색 🟢  (앞뒤)
Z축 = 파란색 🔵  (위아래)

💡 로블록스와 다른 점!
로블록스: Y가 위아래
블렌더:   Z가 위아래
```

## 핵심 단축키 정리

### 필수 단축키

| 단축키 | 기능 | 설명 |
|--------|------|------|
| G | 이동 (Grab) | 오브젝트 움직이기 |
| R | 회전 (Rotate) | 오브젝트 돌리기 |
| S | 크기 (Scale) | 오브젝트 크기 바꾸기 |
| X / Delete | 삭제 | 오브젝트 지우기 |
| Ctrl + Z | 되돌리기 | 실수 취소 |
| Ctrl + Shift + Z | 다시 실행 | 되돌리기 취소 |
| Shift + A | 추가 메뉴 | 새 오브젝트 추가 |
| Tab | 모드 전환 | 오브젝트/편집 모드 전환 |
| N | 사이드 패널 | 정확한 수치 입력 |

### 자주 쓰는 조합

```
G → X → 5 → Enter      : X축으로 5만큼 이동
R → Z → 45 → Enter     : Z축으로 45도 회전
S → 2 → Enter           : 2배로 키우기
S → Z → 0 → Enter       : Z축 크기를 0으로 (납작하게)
S → Shift+Z → Enter     : Z축 빼고 나머지 크기 조절
```

## 오브젝트 모드 vs 편집 모드

```
오브젝트 모드 (Object Mode)
→ 물체 전체를 이동/회전/크기 조절
→ 로블록스에서 파트를 통째로 움직이는 것

편집 모드 (Edit Mode) - Tab 키로 전환
→ 물체의 점, 선, 면을 개별 편집
→ 모양을 자유롭게 바꿀 수 있음!
→ 로블록스에는 없는 기능!

[오브젝트 모드]  ←Tab 키→  [편집 모드]
   🟧 통째로             🔵🔵🔵 점 하나하나
```

## 연습 문제

:::note 실습해보기
1. **뷰포트 조작 연습**
   - 마우스 가운데 버튼으로 화면을 돌려보세요
   - Numpad 1, 3, 7로 시점을 바꿔보세요
   - 휠로 확대/축소해보세요

2. **이동 연습**
   - 기본 큐브를 선택하고 G 키로 이동해보세요
   - G → Z로 위로만 올려보세요
   - G → X → 3 → Enter로 정확히 이동해보세요

3. **회전/크기 연습**
   - R → Z → 45 → Enter로 45도 회전
   - S → 2 → Enter로 2배로 키우기
   - S → Z → 3 → Enter로 위로만 늘리기

4. **편집 모드 체험**
   - Tab 키로 편집 모드 진입
   - 꼭짓점(점)을 하나 선택해서 G 키로 이동
   - Tab 키로 오브젝트 모드로 복귀
:::
