# 기본 오브젝트 모델링

블렌더에서 기본 도형을 추가하고, 편집 모드를 활용해서 원하는 모양으로 바꿔봐요!

## 학습 목표

- 기본 도형(Mesh)을 추가할 수 있다
- 편집 모드에서 점, 선, 면을 편집할 수 있다
- 간단한 게임 에셋(칼, 보석 등)을 모델링할 수 있다

## 기본 도형 추가하기

### Shift + A: 추가 메뉴

```
Shift + A를 누르면:

▼ Mesh (메시)
  ├── Plane       평면 (바닥)
  ├── Cube        큐브 (상자)
  ├── Circle      원
  ├── UV Sphere   구 (공)
  ├── Ico Sphere  다면체 구
  ├── Cylinder    원기둥
  ├── Cone        원뿔
  └── Torus       도넛 모양

💡 로블록스의 Part 추가와 비슷해요!
   Block = Cube, Ball = UV Sphere, Cylinder = Cylinder
```

### 추가 직후 설정

오브젝트를 추가하면 화면 왼쪽 아래에 설정 패널이 나타나요:

```
예: Cylinder 추가 시

Vertices: 32    ← 둘레의 꼭짓점 수
Radius: 1.0     ← 반지름
Depth: 2.0      ← 높이

⚠️ 이 패널은 다른 작업을 하면 사라져요!
   추가 직후에 바로 설정하세요.
```

:::tip 로블록스용 팁
로블록스에 가져갈 모델은 **폴리곤 수를 적게** 유지하세요! Cylinder의 Vertices를 8~16으로 줄이면 게임 성능이 좋아져요.
:::

## 편집 모드 기초

### 모드 전환

Tab 키를 눌러 편집 모드로 들어갑니다.

### 선택 모드 3가지

```
편집 모드 상단 왼쪽에 3개 버튼:

[●] 점 모드 (Vertex)  - 1 키
[/] 선 모드 (Edge)     - 2 키
[■] 면 모드 (Face)     - 3 키

점(Vertex): 꼭짓점 하나하나를 선택
선(Edge):   두 점을 잇는 선을 선택
면(Face):   면 전체를 선택
```

### 편집 도구

**돌출 (Extrude) - E 키**
```
면을 선택하고 E 키 → 쑥! 튀어나옴

  ┌──┐         ┌──┐
  │  │    →    │  │──┐
  └──┘         └──┘──┘

게임 에셋 만들 때 가장 많이 쓰는 도구!
```

**내부 면 만들기 (Inset) - I 키**
```
면을 선택하고 I 키 → 면 안에 작은 면 생성

  ┌──────┐         ┌──────┐
  │      │    →    │ ┌──┐ │
  │      │         │ │  │ │
  └──────┘         │ └──┘ │
                   └──────┘
```

**루프 컷 (Loop Cut) - Ctrl + R**
```
Ctrl + R → 오브젝트 위에 마우스 → 노란 선 표시 → 클릭

  ┌──────┐         ┌───┬──┐
  │      │    →    │   │  │
  │      │         │   │  │
  └──────┘         └───┴──┘

면을 나눠서 더 세밀한 편집이 가능해져요!
```

**베벨 (Bevel) - Ctrl + B**
```
선을 선택하고 Ctrl + B → 날카로운 모서리를 둥글게

  ┌──┐         ╭──╮
  │  │    →    │  │
  └──┘         ╰──╯

부드러운 느낌을 줄 때 사용!
```

## 실습: 간단한 칼 만들기

### 1단계: 칼날 만들기

```
1. 기본 큐브 선택
2. S → X → 0.1 → Enter (얇게)
3. S → Z → 3 → Enter (길게)
4. Tab 키로 편집 모드 진입
```

### 2단계: 칼날 끝 뾰족하게

```
1. 면 모드 (3 키)
2. 칼날 위쪽 면 선택
3. S → X → 0 → Enter (한 점으로 모으기)
```

### 3단계: 손잡이 만들기

```
1. Tab 키로 오브젝트 모드 복귀
2. Shift + A → Mesh → Cube (새 큐브 추가)
3. S → 0.3 → Enter (작게)
4. S → Z → 1.5 → Enter (위아래로 늘리기)
5. G → Z → -3.5 → Enter (칼날 아래로 이동)
```

### 4단계: 합치기

```
1. 칼날 선택
2. Shift + 클릭으로 손잡이도 선택
3. Ctrl + J (Join - 하나로 합치기)
```

## 수정자 (Modifier) 맛보기

수정자는 오브젝트에 효과를 자동으로 적용하는 도구예요.

### 미러 수정자 (Mirror)

```
반쪽만 만들면 나머지 반쪽이 자동으로!

  ┌──╮              ╭──┬──╮
  │  │      →       │  │  │
  └──╯              ╰──┴──╯
  반쪽만 모델링      자동으로 대칭!
```

사용법:
1. 오브젝트 선택
2. 속성 패널 → 🔧 (렌치 아이콘) → Add Modifier
3. **Mirror** 선택
4. Clipping 체크 (중앙을 넘어가지 않게)

### 서브디비전 서피스 (Subdivision Surface)

```
각진 모양을 부드럽게!

  ┌──┐         ╭────╮
  │  │    →    │    │
  └──┘         ╰────╯
  각진 큐브      부드러운 공 모양

⚠️ 로블록스용 모델은 Level을 1~2로 낮게!
   너무 높으면 폴리곤이 많아져서 게임이 느려져요.
```


## 연습 문제

:::note 실습해보기
1. **도형 추가 연습**
   - Cube, Cylinder, Sphere를 하나씩 추가하고 크기를 다르게 만들어보세요
   - 각 도형을 다른 위치에 배치해보세요

2. **편집 모드 연습**
   - 큐브를 편집 모드에서 점 모드로 꼭짓점을 하나 이동해보세요
   - 면 모드에서 Extrude(E 키)로 면을 튀어나오게 해보세요
   - Loop Cut(Ctrl + R)으로 면을 나눠보세요

3. **칼 만들기**
   - 위 실습을 따라 간단한 칼을 만들어보세요
   - 색깔은 아직 안 입혀도 괜찮아요!

4. **나만의 오브젝트**
   - 기본 도형과 편집 도구를 활용해서 자유롭게 만들어보세요
   - 예: 테이블, 의자, 나무, 집
:::
