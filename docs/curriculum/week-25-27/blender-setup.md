# 블렌더 설치 및 인터페이스

지금까지 로블록스 스튜디오의 기본 파트로 게임을 만들었어요. 이제 **블렌더(Blender)**를 배워서 나만의 멋진 3D 모델을 직접 만들어볼 거예요!

## 학습 목표

- 블렌더를 설치할 수 있다
- 블렌더의 기본 화면 구성을 이해한다
- 로블록스 스튜디오와 블렌더의 차이를 안다

## 블렌더란?

```
블렌더(Blender) = 무료 3D 모델링 프로그램

로블록스 스튜디오: 간단한 파트(상자, 공, 원기둥)
블렌더:           복잡하고 멋진 모양을 자유롭게!

[기본 파트] → 블렌더로 제작 → [커스텀 칼, 방패, 캐릭터, 건물...]
```

### 왜 블렌더를 배울까?

| 로블록스 스튜디오 | 블렌더 |
|------------------|--------|
| 상자, 공, 원기둥만 가능 | 어떤 모양이든 자유롭게 |
| 색 바꾸기 정도 | 디테일한 텍스처 가능 |
| 간단한 건물, 지형 | 캐릭터, 무기, 가구 등 |
| 게임 로직에 집중 | 비주얼에 집중 |

## 블렌더 설치하기

### 1단계: 다운로드

1. 블렌더 공식 사이트(blender.org)에 접속합니다
2. **Download Blender** 버튼을 클릭합니다
3. 운영체제(Windows/Mac)에 맞는 버전이 자동으로 선택됩니다
4. 다운로드를 클릭합니다

### 2단계: 설치

**Windows:**
1. 다운로드된 `.msi` 파일 실행
2. Next → Next → Install
3. 완료!

**Mac:**
1. 다운로드된 `.dmg` 파일 열기
2. 블렌더 아이콘을 Applications 폴더로 드래그
3. 완료!

### 3단계: 첫 실행

1. 블렌더를 실행합니다
2. 스플래시 화면에서 **General** 클릭
3. 기본 큐브가 있는 화면이 나타납니다!

## 블렌더 화면 구성

```
┌──────────────────────────────────────────────────────┐
│  [파일] [편집] [렌더] [창]          상단 메뉴바        │
├──────┬───────────────────────────────────┬───────────┤
│      │                                   │           │
│  도구 │         3D 뷰포트                 │  속성     │
│  바   │    (여기서 모델링해요!)            │  패널     │
│      │                                   │           │
│      │         🟧 ← 기본 큐브            │           │
│      │                                   │           │
├──────┴───────────────────────────────────┴───────────┤
│                    타임라인                            │
└──────────────────────────────────────────────────────┘
```

### 주요 영역

**1. 3D 뷰포트 (가운데)**
- 3D 모델을 보고 편집하는 공간
- 로블록스 스튜디오의 3D 뷰와 비슷해요!

**2. 아웃라이너 (오른쪽 위)**
```
로블록스의 "탐색기(Explorer)"와 같은 역할!

▼ Scene Collection
  ▼ Collection
    📷 Camera
    💡 Light
    🟧 Cube    ← 기본 큐브
```

**3. 속성 패널 (오른쪽)**
```
로블록스의 "속성(Properties)"과 같은 역할!

선택한 오브젝트의 정보를 보여줘요:
- 위치 (Location)
- 회전 (Rotation)
- 크기 (Scale)
```

**4. 도구 바 (왼쪽)**
- 선택, 이동, 회전, 크기 조절 도구
- 모델링 도구들

## 로블록스 스튜디오 vs 블렌더 비교

| 기능 | 로블록스 스튜디오 | 블렌더 |
|------|------------------|--------|
| 오브젝트 목록 | 탐색기 (Explorer) | 아웃라이너 (Outliner) |
| 정보 창 | 속성 (Properties) | 속성 패널 (Properties) |
| 이동 | Move 도구 | G 키 |
| 회전 | Rotate 도구 | R 키 |
| 크기 | Scale 도구 | S 키 |
| 삭제 | Delete 키 | X 키 또는 Delete 키 |
| 되돌리기 | Ctrl + Z | Ctrl + Z |

## 기본 설정 (한국어 변경)

1. Edit → Preferences 클릭
2. Interface 탭 선택
3. Translation 체크
4. Language를 **Korean (한국어)**로 변경
5. 하단의 **Save Preferences** 클릭

:::tip
한국어로 바꾸면 메뉴를 이해하기 쉽지만, 블렌더 튜토리얼 대부분이 영어로 되어 있어서 **영어 그대로 쓰는 것**을 추천해요!
:::
